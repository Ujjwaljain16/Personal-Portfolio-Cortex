## 🧠 SYSTEM OVERVIEW

**CORTEX** is not just a portfolio. It is a **Cognitive Operating System**—a digital extension of my engineering consciousness. It visualizes the internal state of my work, decisions, and architectural patterns in a high-fidelity, interactive control plane.

## 🏗️ ARCHITECTURE

Built on the **"Personal OS"** stack, optimized for aesthetics, performance, and type safety.

### **Frontend Layer**
- **Framework:** Next.js 15 (App Router)
- **Styling:** TailwindCSS + `framer-motion` for complex state transitions.
- **Visuals:** Lucide Icons, custom glassmorphism design system.

### **Data Layer**
- **State:** Zustand global store for "OS-level" state management (focus, simulate mode).
- **Content:** Markdown-driven static content for high performance and portability.
- **Type Safety:** 100% TypeScript coverage with strict Zod schemas.

### **Intelligence Layer**
- **Simulation:** RAG-lite architecture injecting structured `knowledge.ts` into LLM contexts.
- **Context:** Dynamic context injection based on active module and hover states.
